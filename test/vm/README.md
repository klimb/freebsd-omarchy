# test/vm/ — FreeBSD 15.1 test VM (QEMU on Apple Silicon)

Reproducible local VM for building and testing the `freebsd-omarchy` port.
Only the scripts are tracked; disk images, firmware, and keys are git-ignored
(see the repo `.gitignore`) and are regenerated by the steps below.

## First-time setup

```sh
cd test/vm

# 1. Download + prepare the disk image (FreeBSD 15.1 arm64 UFS qcow2)
IMG=FreeBSD-15.1-RELEASE-arm64-aarch64-ufs.qcow2.xz
wget -c "https://download.freebsd.org/releases/VM-IMAGES/15.1-RELEASE/aarch64/Latest/$IMG"
xz -dk "$IMG" && mv "${IMG%.xz}" disk.qcow2
qemu-img resize disk.qcow2 60G

# 2. UEFI firmware pflash (code copied from Homebrew qemu, blank vars)
cp /opt/homebrew/share/qemu/edk2-aarch64-code.fd edk2-code.fd
truncate -s 64m edk2-code.fd
qemu-img create -f raw edk2-vars.fd 64m

# 3. SSH key for the VM
ssh-keygen -t ed25519 -f vm_key -N "" -C freebsd-omarchy-vm
```

## Boot + enable SSH (one-time console step)

```sh
./run.sh serial        # boot; log in as root (empty password)
./vm.sh serve &         # serve this dir so the guest can fetch the key

# On the guest console, paste:
#   fetch -o /tmp/gp.sh http://10.0.2.2:8000/guest-provision.sh && sh /tmp/gp.sh
```

After that, SSH works: `./vm.sh ssh` (key-based, port 2222).

## Everyday use

```sh
./vm.sh ssh [cmd]     # root shell / command in the VM
./vm.sh sync           # push the repo into VM:/root/freebsd-omarchy
./vm.sh install        # run bootstrap/install.sh inside the VM
./vm.sh provision      # sync + install
./run.sh gui           # graphical console (virtio-gpu) for the desktop test
```

## Files

| File | Tracked | Purpose |
|---|---|---|
| `run.sh` | yes | qemu launcher (`serial`/`gui`) |
| `vm.sh` | yes | orchestrator (boot/serve/ssh/sync/install/provision) |
| `guest-provision.sh` | yes | one-time in-guest SSH bootstrap |
| `disk.qcow2`, `edk2-*.fd` | no | disk + UEFI firmware |
| `vm_key`, `vm_key.pub`, `known_hosts` | no | SSH key + host key cache |
